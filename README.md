# NFC Identity Card
A custom-designed NFC business card that allows people to instantly access my digital identity and engineering portfolio by tapping their smartphone against the card. 

# Overview 
The NFC identity card is a physical networking card designed to connect to the physical and digital worlds. By integrating an NFC chip and antenna into a custom PCB, the card allows compatible smartphones to access a personal portfolio website without requiring an application or manual URL entry. 

The website serves as a central hub for my identity, engineering projects, technical experience and contact information. 

# How it works
1. A person brings their NFC compatible smartphone close to the card.
2. The smartphone detects the NFC tag.
3. The phone displays a notification or prompt containing the stored URL.
4. The person taps the notification.
5. The person portfolio website opens in their browser.

The card uses passive NFC technology, meaning it does not require a battery or external power sources. 

# Hardware components 
| Component | Purpose | 
|---|---|
| NTAG213 NFC chip | Stores the portfolio URL | 
| Custom PCB NFC antenna | enables wireless NFC communication |
| Custom PCB | Provides the physical card structure | 
| QR code | Provides an alternative way to access the portfolio | 

# Portfolio website 
The website will act as my personal digital identity and engineering portfolio 

Planned sections include: 
- **About me**: Personal introduction and engineering interests.
- **Projects**: A collection of hardware, software and engineering projects.
- **Skills**: Programming languages, electronics, CAD, and technical experience.
- **GitHub**: Links to my repositories and development work.
- **Contact**: Ways to connect with me

# PCB Design
The card will feature a custom PCB layout with an integrated NFC antenna. 

The design will prioritize: 
- Credit-card-sized dimensions.
- Reliable NFC communication.
- Proper antenna layout and tuning
- Durable PCB construction
- Clean and professional visual design.
